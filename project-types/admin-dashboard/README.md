# Admin Dashboard Template

## Type Definition

Use this template for back-office systems centered on forms, tables, filters, permissions, state transitions, and audit-style operations.

## Inspect First

- route config
- layout shell
- page modules
- request layer
- permissions
- shared form or table abstractions

## Common Task Shapes

- add list page
- add form or detail page
- add filter or export
- change state-transition flow
- adjust permission logic
