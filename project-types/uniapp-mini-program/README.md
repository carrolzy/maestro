# Uniapp Mini-Program Template

## Type Definition

Use this template for uniapp and mini-program projects centered on page flow, platform behavior, login, sharing, payment, and review constraints.

## Inspect First

- `pages.json`
- route pages
- request wrapper
- shared components
- state management
- platform-specific code paths

## Common Task Shapes

- add page
- modify interaction
- login or auth flow
- share or payment integration
- platform-difference handling
