# Non-Trivial Work Must Sync

## Rule

After non-trivial coding, debugging, refactoring, or architecture work:

1. write back to Obsidian
2. sync the note into the AI efficiency system memory

## Why

If project knowledge only lives in task threads or raw Obsidian notes, future tasks still pay the same rediscovery cost.

## Promotion Rule

If the same kind of incident appears more than once:

- create or update a pattern note

If the same safeguard should always apply:

- create or update a rule note
